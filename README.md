# perl-Essentials

A collection of perl modules for performing common functions.

For more information on the distributions contained within this repository, see the links below.

| Distribution | Description |
|--|--|
| [perl-Essentials-Beanstalk](perl-Essentials-Beanstalk/README.md "perl-Essentials-Beanstalk") | Beanstalk job queue consumers and producers |
| [perl-Essentials-Config](perl-Essentials-Config/README.md "perl-Essentials-Config") | Application configuration in varying formats |
| [perl-Essentials-DB](perl-Essentials-DB/README.md "perl-Essentials-DB") | Thread-safe `DBIx::Class` schemas under custom namespaces |
| [perl-Essentials-Exception](perl-Essentials-Exception/README.md "perl-Essentials-Exception") | Throwable exception objects with stack traces |
| [perl-Essentials-Log](perl-Essentials-Log/README.md "perl-Essentials-Log") | Simple and flexible structured logging |
| [perl-Essentials-Script](perl-Essentials-Script/README.md "perl-Essentials-Script") | Modular scripts and services |
